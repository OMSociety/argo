# Argo v2.9.9 发布说明

**版本**：2.9.9
**定位**：安全纵深 + 交付质量。三条主线：内容与网络出口的安全加固（高风险正文隔离、逐跳重定向校验、DNS 重绑定封堵）、调度与学习重构（早停弃置的慢源交付不再丢弃、场景分桶学习）、路由精度的六族真实场景扫描收口；另有 `argo engine add` 一键接入与 ZCode 插件包两个能力扩展。

---

## 这次更新有什么（通俗版）

### 1. 高风险网页内容不再原样进上下文（风险门禁）

**以前**：内容安全引擎只「评分」，`risk_score` 等元数据回传了，清洗后的正文却被丢弃——安全引擎只评分不门禁，高风险注入页照样进证据流水线与 Agent 上下文。

**现在**：`risk_score ≥ 0.5`（阈值可调）的正文被隔离：用清洗后正文替换原始正文、标 `content_quarantined`、`content_ok=false`，且不进证据分（与 `--verify` 联动）。默认开启，`ARGO_CONTENT_RISK_GATE=0` 应急放行，`ARGO_CONTENT_RISK_THRESHOLD` 调阈值。

### 2. 网络出口纵深防御

**以前**：主抓取路径的内联重定向循环只校验第一跳，重定向到内网即可绕过 SSRF 防护；DNS 解析与 TCP 连接之间存在重绑定窗口。

**现在**：

- 重定向逐跳校验，跳数上限 `ARGO_MAX_REDIRECTS`（默认 5）
- 解析即锁定：DNS 解析一次、过滤私网、把结果钉给本次 TCP 连接，堵住 check 与 connect 之间的 DNS 重绑定窗口；SNI/Host 仍用原域名
- 数字 IP 字面量直接查表判定，不再依赖解析器；直连显式校验 TLS 上下文（`check_hostname` + `CERT_REQUIRED`）

### 3. 早停弃置的慢源交付不再丢弃

**以前**：74% 的查询发生早停，被放弃的交付 81% 来自 anysearch（相关度高于均线）；五条对照查询里四条唯一有结果的正是慢源。早停省的是等待，连交付一起丢是拿准确性换速度。

**现在**：早停弃置的引擎转入后台收割，宽限窗内完成的照常交付（`ARGO_TAIL_COMPLETE_S`，默认 3 秒，0=关）：学习器记真实成绩（此前 cancelled 一律跳过，慢源真实表现从没进过学习器）、交付按 URL 去重合并写回 L2 缓存（同查询第二次免费拿全量覆盖）。CLI 输出先行、退出前等宽限，MCP/daemon 常驻进程自然收割；真超窗的 timeout 弃置不收。

### 4. 路由精度：六族真实场景扫描，五类误路由收口

按 97 域全景构造真实场景探针电池（目标类目 + 边界反例 + 既有域回归）离线实测，五类实锤全部按「让位 unless + 收口 match/unless 成对改动」修：

- **学术**：论文写作 howto（怎么写/查重/盲审）不再落学术检索域；综述语境不再被 AI 模型域的「模型+上下文」抢走
- **金融/财务**：A 股企业的年报/营收/毛利率/市盈率查询此前落只认 CIK 的 SEC 源（全空）——中文词形财务查询统一进 `stock_query`（sina/eastmoney 双地覆盖），英文词形与美股标记进美股域，美股域中文词形全部让位
- **企业主体**：尽调风险（注销/吊销/经营异常/行政处罚）、开票信息、人查公司（法定代表人/名下公司/实际控制人）三类此前落 wikidata 组合（中文企业空结果率 82%）——统一收口进 `company_search`，「公司注销流程 怎么办」这类办事指南形态不误吸
- **法律**：民事实务（劳动合同/工伤/民间借贷/婚姻/继承/侵权赔偿）进 `flk_law`，不再落通用域；岗位/薪资仍归求职
- **医药**：药品说明书/用法用量不再被 code_search 的「用法」子串抢走（GitHub/MDN 答不了药）

### 5. 遥测去污 + 权威源加权补表

- 测试夹具引擎名三次绕过隔离写进生产使用日志——在唯一落盘口反向判定，注册表外引擎名的整条拒写；存量 63 条隔离留档。stats 均值 2295→1855ms，假引擎（slow/fast）从最慢榜消失，真实慢尾（skillsmp/anysearch）露出
- 12 个学术聚合/官方一手源（core/sec_edgar/federal_register/eu_opendata/egov_law/openstd/who_gho/usgs/nasa_cmr=1.3，zenodo/datacite=1.2）补融合权重——此前独家交付却拿基线 1.0

### 6. 调度层确定性重构

时间读写统一走 `clock()`（测试注入虚拟时钟，生产回退 monotonic）；等待一律按剩余预算（deadline 语义）判断，单次轮询抖动不再累加；完成判据从 `Thread.is_alive()` 改为 `holder[done]`，消除「跑完最后一行到被观测之间」的误判窗口——调度类用例在全量套件里间歇性红的共同根因。

### 7. 能力扩展

- **`argo engine add`**：写 spec→设 env→验证→同步→改 combo→补白名单→补语料的人工多步链编排成一步。三档：`--from-yaml` 安装+验证+准入、`--from-url` 探测+生成模板、`--engine` 只补元数据；幂等、`--dry-run`、判不准的字段保守留空
- **场景分桶学习**：自适应学习按 `(engine, domain, lang)` 分桶聚合，与全局分加权融合（桶样本 <3 权重 0.3，≥3 权重 0.5）——「引擎在 A 域强、B 域弱」从此可被路由区分，新引擎也能在建议域里被更快识别
- **ZCode 插件包**：skill 与 CLI 白名单为主通道、零 token 面板（MCP 每轮注入清不掉的问题绕开），已进 [zcode-plugins#120](https://github.com/zai-org/zcode-plugins/pull/120)
- **DSH 设置页**：新增路由观测卡片（只读本机 usage_log/route.jsonl 汇总最近路由决策，无日志不假装有数据）与工具推荐组合（按场景一键套用工具勾选）
- **慢源质量实证**：尾宽 A/B 回放基准（2721 条真实日志离线回放）+ 实证文档 `docs/QUALITY_OF_SLOW_SOURCES.md`——缩全局尾宽是拿准确性换速度，正确方向是早交付+后台补全

### 8. 离线评测自愈重入

缺 PyYAML 的解释器跑离线评测时，config 会静默回落内置默认引擎集，route 段整片假红（同机实测 94 FAIL vs 197 全绿，差异全在解释器不在路由）。守卫升级为自愈重入：按 `ARGO_PYTHON` → PATH 上 python3.14/3.13/3.15/3.12 → python3 的候选序逐个真验 import，找到即 `execv` 重入；换无可换才报错并给修法。

## 验证

- 全量 `python3.14 -m pytest -q` 退出码 0（4625 用例，少量平台性 skip）
- pre-commit 七门（静态检查/体积门禁/开关总表/五语一致性/路由快照/上下文预算/引擎目录）全绿
- 路由探针电池 30/30；matrix 离线评测绿 0 红（路由段 212 用例）
- 早交付端到端实证：skillsmp 被弃置 990ms 后收割线程等到其 2205ms 完成交付，学习器落真实成绩
- 真实查询复验：合成开票查询从 wikidata 空结果回到 company_search（元宝交付）；学术域 core 独家交付查询加权后排基线源之上

- 无破坏性变更，v2.9.8 的配置与用法继续有效
- 新增开关：`ARGO_TAIL_COMPLETE_S`（默认 3，0=关）、`ARGO_CONTENT_RISK_GATE`（默认开）、`ARGO_CONTENT_RISK_THRESHOLD`（默认 0.5）、`ARGO_MAX_REDIRECTS`（默认 5）
- 两处金标随约定更新：中文财务词形期望统一进 `stock_query`；其余既有查询行为不变
